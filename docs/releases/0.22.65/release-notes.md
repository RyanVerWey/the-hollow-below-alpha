The Hollow Below alpha 0.22.65 for Windows 10/11, 64-bit.

**Start here:** [Download the Windows installer](https://github.com/RyanVerWey/the-hollow-below-alpha/releases/download/v0.22.65/The-Hollow-Below-Alpha-Setup.exe), open it, and choose **Install**. Open the installed launcher and choose **Play game**.

The standard NSIS installer includes the complete game, a branded launcher, desktop and Start menu shortcuts, and a Windows uninstaller. The launcher checks for updates on startup. Choose **Update & restart** to download and verify the full installer, apply the update, and reopen the launcher. Close the game first. Existing testers using an older launcher must install this release once to enable this feature. Re-running the full installer also repairs game files. Installed play works offline. No Unity editor, Node.js or administrator access is needed.

- Planning maps now show the maze paths and entrance without possible-objective circles or area labels. Unfound objective sites stay hidden until discovered.
- Found and restored objectives, earned player and teammate tracking, and the final hunter sound/hunt range upgrades are retained.
- Updated the safe-room boards and planning instructions to match the cleaner map. Both playable levels retain all four difficulties and randomized objective sites.
- Compact Briarwake ward placements now reserve clearance for the hedge foliage as well as its solid boundary, including tucked corner sites. Centre walking lanes remain clear.
- Includes the 0.22.64 stationary-player capture correction. No new demon model is integrated. Windows only; close the game and use Update & restart in the launcher. Everyone in a lobby should use the same build.

Prepare in the safe vestibule. Press **TAB** for objectives and survival instructions, or **M** for the maze survey before entry. The survey shows paths and the entrance; objective sites remain hidden until discovered. Open the station door with **E**, then cross its threshold to start the hunt; the door seals behind you. Restore INTAKE, FILTRATION and FLOODGATE in any order, then return to the green surface gate.

For a portable installation, download **The-Hollow-Below-Alpha-0.22.65-Windows.zip**, extract it completely, then open **The Hollow Below.exe**. Players do not need the `windows-XX.bin` compatibility files.

This is unsigned early alpha software. Windows may show a publisher warning. Keyboard and mouse only; no saved progress yet. Contains jump scares, blood, frightening imagery and sudden loud sounds.
