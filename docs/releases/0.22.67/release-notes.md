The Hollow Below alpha 0.22.67 for Windows 10/11, 64-bit.

**Start here:** [Download the Windows installer](https://github.com/RyanVerWey/the-hollow-below-alpha/releases/download/v0.22.67/The-Hollow-Below-Alpha-Setup.exe), open it, and choose **Install**. Open the installed launcher and choose **Play game**.

The standard NSIS installer includes the complete game, a branded launcher, desktop and Start menu shortcuts, and a Windows uninstaller. The launcher checks for updates on startup. Choose **Update & restart** to download and verify the full installer, apply the update, and reopen the launcher. Close the game first. Existing testers using an older launcher must install this release once to enable this feature. Re-running the full installer also repairs game files. Installed play works offline. No Unity editor, Node.js or administrator access is needed.

- Added host-selectable 1–4 hunters and a solo hunter-count control. Hunters keep independent targets, sound memories and attack clocks, with separated starts and reserved movement space.
- Co-op loading now shows every survivor, stage progress from 0–100%, the current build phase and time since last progress. The group can return to the lobby; stalled or failed loading recovers the connected group.
- Blackwater and Briarwake construct their online worlds in batches so the loading display and network can keep updating. 100% is shown only after a completed world is acknowledged by the host.
- Refined survivor walking, running and turning with stable limb bend planes. Camera-specific head and neck hiding prevents viewing inside another survivor during close encounters and spectating.
- Voice chat uses proximity during a run, louder near speech, bounded speech leveling, and a verified higher-rate codec configuration. Speaking attracts each hunter independently; sustained nearby speech can start a hunt on every difficulty.
- Added short original Suno menu hover and confirm effects, restrained return feedback, debounce, and a separate Menu feedback volume slider. Two tracks used from the new three-download allowance.
- Includes the four difficulty skulls and clean launcher Uninstall from 0.22.66.
- Windows only. Close the game, then choose Update & restart in the launcher. Every player in a lobby needs this version because voice and multiplayer messages changed.

Prepare in the safe vestibule. Press **TAB** for objectives and survival instructions, or **M** for the maze survey before entry. The survey shows paths and the entrance; objective sites remain hidden until discovered. Open the station door with **E**, then cross its threshold to start the hunt; the door seals behind you. Restore INTAKE, FILTRATION and FLOODGATE in any order, then return to the green surface gate.

For a portable installation, download **The-Hollow-Below-Alpha-0.22.67-Windows.zip**, extract it completely, then open **The Hollow Below.exe**. Players do not need the `windows-XX.bin` compatibility files.

This is unsigned early alpha software. Windows may show a publisher warning. Keyboard and mouse only; no saved progress yet. Contains jump scares, blood, frightening imagery and sudden loud sounds.

Known alpha limitation: some survivor shoulder clothing still needs refinement. Four-player voice and session recovery were tested with separate native processes on one PC; microphone hardware and Internet conditions need playtester feedback.
