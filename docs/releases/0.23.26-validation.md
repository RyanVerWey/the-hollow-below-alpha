# Alpha 0.23.26 validation

This release lowers the Widow's floor stance, adds bounded pursuit bursts, preserves planted feet during remote interpolation, and isolates continuous audio from transient mix peaks.

Local verification used the frozen Windows export:

- 568 functional checks and 19 rendered UI/world captures.
- Four actual Internet Relay peers: 632 checks across both levels, persistent lobby and fresh return to the menu. 36 burst mode/phase receipts and four reset receipts were additionally audited.
- 234 isolated installer upgrade checks, including launching the installed payload with its bundled runtime.
- 55 burst-controller checks and six rendered generated-maze checks, including escape around a real hedge corner.
- All-species navigation matrix: 641 checks; the subsequent Widow-only recenter correction passed 277 checks and 27 shed/traffic checks.
- New floor animation: 112 contact, 59 skinned-mesh and 21 head/attack checks. The actual corner skin sweep had no penetrating vertices.
- Exact-export audio recording: 286 footsteps over 491 metres; the complete 184.4-second music track and loop boundary remained sample-continuous. Footstep callback work fell about 84%; the existing audible gain and AI noise detection are unchanged.
- The reproduced co-op mix overload fell from peak 1.2703 to 0.8231. Machinery now uses a separate room return and limiter from footsteps and voices.

The recurring player-reported solo cutout has not been conclusively reproduced. The native music stream remained continuous, while Windows recordings included unrelated output. This is not proof of headphone/hardware output quality or that every reported cutout is resolved. An optional `Diagnose Audio.cmd` in the game folder records 25 seconds of solo game output and timing, beginning on the first step. It does not record the microphone or multiplayer and uploads nothing.

Tests are scripted. Physical microphone quality, separate-household networking and manual Windows overlay use are not established by these checks. Builds and tests ran locally; only the existing authorized built-in Pages deployment publishes the site.
