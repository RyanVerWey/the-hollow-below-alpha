# The Hollow Below / Alpha 0.22.58

Difficulty selection now shows each tier's actual maze at a common scale, with grid dimensions and physical width. Objective positions are never shown in the preview.

Every Blackwater and Briarwake difficulty has 24 reserved objective locations, with eight possibilities for each of the three objectives. A fresh run selects three spaced, reachable sites using its run seed; pausing keeps the current plan.

Blackwater grows from 59x59 cells on Easy to 63x63 Normal, 67x67 Hard and 71x71 Nightmare. Briarwake grows through 41x41, 49x49, 57x57 and 65x65. These are actual physical layouts, not only difficulty labels.

Briarwake's new possible ward sites retain separate courtyards, tight connecting paths, and nearby always-unlocked refuges, including on Nightmare. Blackwater cabinet sites keep clear wall bays and broad planning-survey guidance.

The host still supplies the shared run seed, maze and objective plan in co-op. Each participant sees the same world. New rounds select a new seed; objectives stay hidden until discovered.

Voice Chat settings, push to talk or open mic, aligned level folders, refined survivor equipment, scoreboards and retained co-op parties are included from previous builds. Blackwater and Briarwake are playable; The Last Harvest and The Ossuary remain Coming Soon.

Windows download only. Close the game, then choose Update & restart in the launcher. Everyone in a lobby should update to the same build.
