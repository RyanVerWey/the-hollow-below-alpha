The Hollow Below alpha 0.22.66 for Windows 10/11, 64-bit.

**Start here:** [Download the Windows installer](https://github.com/RyanVerWey/the-hollow-below-alpha/releases/download/v0.22.66/The-Hollow-Below-Alpha-Setup.exe), open it, and choose **Install**. Open the installed launcher and choose **Play game**.

The standard NSIS installer includes the complete game, a branded launcher, desktop and Start menu shortcuts, and a Windows uninstaller. The launcher checks for updates on startup. Choose **Update & restart** to download and verify the full installer, apply the update, and reopen the launcher. Close the game first. Existing testers using an older launcher must install this release once to enable this feature. Re-running the full installer also repairs game files. Installed play works offline. No Unity editor, Node.js or administrator access is needed.

- The launcher now offers Uninstall beside Verify game files. Its confirmation explains that removal includes the installed game, launcher, settings, saved player name, logs and downloaded updates. Cancel keeps the installation.
- Uninstall waits for the launcher to close, asks you to close a running game, checks its installation marker and avoids linked cleanup folders. Windows Installed apps uses the same uninstaller.
- Replaced the tiny difficulty-menu maze previews with four original skull emblems: intact bone for Easy, fractured bone for Normal, horns for Hard, and a crowned ram-horn demon for Nightmare.
- Both playable levels use the same aligned artwork, captions and selection buttons. Actual maze width and randomized-objective information remain visible beneath each skull.
- Menu artwork is cached and imported at a limited texture size. Difficulty selection no longer generates unused maze thumbnail textures.
- Retains the cleaner maps, randomized objectives, Briarwake ward clearance and stationary-player capture correction from the previous releases. No new monster model is integrated.
- Windows only. Close the game and choose Update & restart in the launcher. Everyone in a lobby should use the same build.

Prepare in the safe vestibule. Press **TAB** for objectives and survival instructions, or **M** for the maze survey before entry. The survey shows paths and the entrance; objective sites remain hidden until discovered. Open the station door with **E**, then cross its threshold to start the hunt; the door seals behind you. Restore INTAKE, FILTRATION and FLOODGATE in any order, then return to the green surface gate.

For a portable installation, download **The-Hollow-Below-Alpha-0.22.66-Windows.zip**, extract it completely, then open **The Hollow Below.exe**. Players do not need the `windows-XX.bin` compatibility files.

This is unsigned early alpha software. Windows may show a publisher warning. Keyboard and mouse only; no saved progress yet. Contains jump scares, blood, frightening imagery and sudden loud sounds.
