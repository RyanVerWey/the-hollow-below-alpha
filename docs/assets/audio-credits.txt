Survivor locomotion reference and retargeted motion curves use trials35_01
(walk) and35_17 (run/jog), subject35, at120Hz, from the Carnegie Mellon
University Graphics Lab Motion Capture Database.

Database and usage terms: https://mocap.cs.cmu.edu/
FAQ: https://mocap.cs.cmu.edu/faqs.php
The database permits use in commercially sold products; the dataset itself
must not be resold directly, including converted copies. The game distributes
game-specific retargeted motion, not a resale of the raw source library.

The data used in this project was obtained from mocap.cs.cmu.edu.
The database was created with funding from NSF EIA-0196217.

Source references, hashes, skeleton and source videos are retained in the
development project's ArtSource/Motion/CMU-reference directory. These raw
reference files are not copied into the Windows game package.
MakeHuman CC0 model assets are credited separately in Survivor-Assets.txt.

The reference image is concept/texture art, not a 3D asset or gameplay capture.

Core asset source: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html

presentation derives from CMU references with runtime foot planting and arm IK;
see Motion-Capture-CMU.txt. No raw CMU capture library is distributed.
