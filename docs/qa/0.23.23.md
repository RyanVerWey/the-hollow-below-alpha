# Alpha 0.23.23 validation

Validated locally on Windows on November 4, 2026. The release uses the existing installer, website and launcher update feed.

## Changes

The Widow now has twelve authored Blender actions, staggered eight-leg contacts, planted claws, compact corner steps and continuous floor/wall pose changes. Separate positional soil and hedge sounds follow its actual contacts. Revised hunt voices distinguish the Widow and Thornkeeper. Bite/grab contact and recovery remain visible before results or spectating.

Hunter navigation uses reachable shed approaches and coordinated yielding. Nearby ground pursuit avoids repeated unnecessary climbing. A successful capture stops the physical lunge while the animation finishes.

The final native movement trace measured at most 3.06 mm of frame-to-frame planted-foot displacement and 4.14 mm across a stance. It retained at least three supporting legs. The prior corner and wall-transition knee flips were removed. Fast stride motion was checked against the actual authored motion at its playback speed, with separate abrupt-motion checks.

Controller regressions also passed 6,921 traversal checks, 21 edge cases and 27 shed cases. A swept target walking at the normal player speed of 3.05 m/s was captured from both floor and existing-wall pursuit starts; these are controlled scenarios, not universal encounter timings.

One initial four-peer run timed out waiting for a build receipt while other native suites were running. The unchanged frozen build subsequently passed both complete rounds. The timeout is retained in local evidence; its cause was not conclusively established.

The export forbids command-line scene overrides. Consequently, the detailed movement review loaded the exact frozen DLL/PCK in an isolated harness using the same Godot 4.7.2 renderer. The separate functional and visual checks launched the actual retail EXE. No production startup hook was added for the harness.

These checks do not establish separate-household network quality, subjective headphone quality, hardware microphone behavior or manual Windows-overlay behavior. No player preferences or foreign processes were modified. No custom GitHub Actions workflows were used; publication retains the previously authorized built-in Pages deployment.
