# Alpha 0.23.24 validation

Validated locally on Windows. This update retains the existing website,
installer and launcher feed. The Widow's model and size are unchanged.

## Changes

The Widow uses a Godot NavigationRegion3D and NavigationAgent3D for its floor
route. Lookahead steering rounds bends, anticipatory leg folding provides room,
and the existing wall traversal remains active. Traffic reservations select
alternate corridors while physical yielding handles shared passages.

Bite/grab windup and recovery continue pursuing. The rear legs keep stepping
under the authored attack poses. The committed strike, damage window and brief
post-capture hold remain, preserving dodge opportunities and a visible contact.

Breaker buzz now loops in the native audio mixer rather than restarting on a
game frame. Ground and hunter cues preload during level loading.

## Failures caught before publication

The first export exposed an empty navigation region despite a completed mesh.
Changing the query point and force-syncing did not fix it. The map now stays
inactive until its completed mesh is assigned, avoiding an empty asynchronous
registration overtaking the geometry update. Final actual-EXE visual and native
movement runs pass with no engine errors. No forced synchronization remains.

Passing-lane tests also caught centre-biased steering pointing backward and
traffic slowdowns feeding back into navigation acceleration. Offset passing
lanes now retain their original funnel route and receive the intended speed.

Audio captures reproduced 14–68 ms gaps in the old breaker loop. The revised
loop remains continuous through an injected 150 ms main-thread stall. Both
ambient tracks remained sample-continuous across 426 sampled windows in the
final build. The reported music stutter did not reproduce, so this release does
not claim to fix every possible audio-driver or hardware issue.

Detailed movement checks use the exact frozen DLL/PCK in the same-version
Godot renderer because retail builds forbid scene overrides. Separate checks
launch the actual retail EXE. Physical microphones, separate households and
manual Windows-overlay behavior are not established by these automated tests.
No player preferences or unrelated processes were modified.

All checks and builds ran locally. Publication uses only the previously
authorized built-in GitHub Pages deployment; no custom Actions workflows.
