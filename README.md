# The Hollow Below

Free Windows horror alpha. Solo and private 2–4 player co-op. Keyboard and mouse.

## Play

- **[Official playtest website](https://ryanverwey.github.io/the-hollow-below-alpha/)**
- **[Download the Windows installer](https://github.com/RyanVerWey/the-hollow-below-alpha/releases/download/v0.22.53/The-Hollow-Below-Alpha-Setup.exe)**

- [Release files and notes](https://github.com/RyanVerWey/the-hollow-below-alpha/releases/tag/v0.22.53)

On Windows, open the installer, choose **Install**, then open the launcher and choose **Play game**. Desktop and Start menu shortcuts are included. The launcher checks for updates when opened. Choose **Update & restart** to download, verify and install a newer release, then reopen the launcher. Close the game first. Installed play works offline. Launchers from before this feature need the latest full installer once. Portable copies are updated manually. No administrator access or game development tools are required.


Windows 10/11. Contains jump scares, blood and sudden loud sounds. Early unsigned alpha software; Windows may show a publisher warning. No saved progress or controller support yet. Co-op requires Internet and the host must stay connected.

This repository contains the public website and downloadable alpha release files. It does not contain the Unity development project. Game and artwork rights are reserved except for credited third-party assets. [Audio credits](https://ryanverwey.github.io/the-hollow-below-alpha/assets/audio-credits.txt).

## Play with friends

Choose **Play with Friends**, enter your name and host a private lobby. Share the invite code with up to three friends. They join using the code, choose an available survivor and ready up. The host chooses either level and difficulty, then starts the descent. You begin in separate sectors and share objective progress. Each survivor must escape; dead or escaped players spectate. Online menus do not pause the hunt. The host must keep the game open. Co-op requires Internet; solo remains offline.

## Controls

WASD move, mouse look, Shift sprint, C/Ctrl crouch, F flashlight, E interact/hide, Tab objectives and instructions, M survey while staging or field map after breaker 1, Escape pause/resume. Prepare in the safe vestibule, then open the station door and cross to start the run. Restore INTAKE, FILTRATION and FLOODGATE in any order, then return to the green surface gate.

Briarwake Estate is also playable from Level Select: study the safe potting house, restore three beneficial wards, and return to its estate gate. M unlocks after any ward. Wind Bell adds player tracking. Tool shelters replace lockers. All four difficulties are available in both levels. Corn Maze and Stone Labyrinth remain Coming Soon.
