# The Hollow Below

Free Windows horror alpha. Single-player, keyboard and mouse.

## Play

- **[Official playtest website](https://ryanverwey.github.io/the-hollow-below-alpha/)**
- **[Download the Windows installer](https://github.com/RyanVerWey/the-hollow-below-alpha/releases/download/v0.12.0/The-Hollow-Below-Alpha-Setup.exe)**
- [Release files and notes](https://github.com/RyanVerWey/the-hollow-below-alpha/releases/tag/v0.12.0)

Open the installer, choose **Install**, then open the launcher and choose **Enter the station**. Desktop and Start menu shortcuts are included. The launcher checks for updates when opened. Choose **Update & restart** to download, verify and install a newer release, then reopen the launcher. Close the game first. Installed play works offline. Launchers from before this feature need the latest full installer once. Portable copies are updated manually. No administrator access or game development tools are required.

Windows 10/11, 64-bit. Contains jump scares, blood and sudden loud sounds. Early unsigned alpha software; Windows may show a publisher warning. No saved progress, multiplayer or controller support yet.

This repository contains the public website and downloadable alpha release files. It does not contain the Unity development project. Game and artwork rights are reserved except for credited third-party assets. [Audio credits](https://ryanverwey.github.io/the-hollow-below-alpha/assets/audio-credits.txt).

## Controls

WASD move, mouse look, Shift sprint, C/Ctrl crouch, F flashlight, E interact/hide, Tab objectives and instructions, M survey while staging, Escape pause. Prepare in the safe vestibule, then open the station door and cross to start the run. Restore INTAKE, FILTRATION and FLOODGATE in any order, then return to the green surface gate.
